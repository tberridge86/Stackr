# Rev 2 Asset Structure

The numbered folders are the app-facing asset structure. Static app references should point here.

- `01-brand`: app icons, splash, wordmarks, and backdrops.
- `02-navigation-icons`: footer, tab, and core product icons.
- `03-ui-illustrations`: small UI illustrations, mascots, and hero support art.
- `04-listing-categories`: marketplace listing category artwork.
- `05-binder-covers`: binder cover cutouts and custom binder name art.
- `06-profile-teams`: team logos and profile avatar artwork.
- `07-achievements`: achievement badges and binder rewards.
- `08-pokedex-regions`: region artwork used by Pokedex views.
- `09-grading-master-set`: slab, grading, and master set UI artwork.
- `10-market-trade`: market and trade protection artwork.

Older asset folders are intentionally left in place until they have been audited visually and can be removed safely.
