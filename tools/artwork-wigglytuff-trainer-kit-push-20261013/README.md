# Wigglytuff Trainer Kit artwork: 28 verified fronts

This route prepares 28 exact English fronts from the original 29 saved targets
in EN-CARDS-036 and EN-CARDS-037. The actual saved references are 1–23,25–30;
24 is absent. Original identities come from the hash-matched combined
EN-CARDS-036–038 canonical snapshot, filtered to the exact 29 Wigglytuff
source-map identities. No other deck is included and no whole-batch completion
is claimed.

Wigglytuff 30/30, printing `2d0861db-c750-425b-be9a-452a104f884d`, variant
`ce663658-cadb-422f-a080-f4295937f838`, remains excluded and unacquired: its
canonical finish is normal, but exact source `tk7a-30` lists only holofoil.
Joint row/table relabelling cannot admit it. The earlier 18 named holds remain
outside this cohort, making 19 actual named holds including this card.

`saved-targets.json` pins the original identities, and the independently hashed
identity table pins only the eligible 28 printing UUIDs, singleton normal
variants, canonical names/references, source metadata names, original hashes,
dimensions and full actual pixel-observation objects. Canonical `tk-xy-w` maps
to source `tk7a`. All actual English bodies, numbers out of 30, distinct pink
Wigglytuff badges and copyright 2014 were individually inspected. No release-year
or physical-capture inference is made.

Jigglypuff 12 and 25 print a Darkness icon within Heartfelt Song; provider text
expands that icon as the word Darkness. This is a matched symbol representation
and remains a source fact, with no text discrepancy or canonical repair.
Wigglytuff 14 was separately checked in full: Balloon Barrage Colorless 20×,
Double-Edge Fairy/Fairy/Colorless 90 with self damage 10, 100 HP, Kagemaru Himeno,
14/30, 2014 and pink badge. Printed fields/types remain unchanged in the evidence.

All 28 originals are unchanged 728×1018 PNGs. The quality gate requires at least
576×800, readable names/numbers/symbols and fine print, and a complete printed
face/frame. Three WebP derivatives per front never enlarge the original. This
actual package has no shared image paths. Compatible display aliases are handled
by the accepted immutable object index; conflicting aliases or shared originals
are rejected. No generation, physical corner certification or certified foil
is asserted.

The owner authorised exact artwork store/resize/display without another human
batch review. `approval.json` records the finite 28-front decision; independent
vendor licence and physical finish certification remain unestablished, and
source-wide approval remains false. Existing Scrydex remains inactive and under
review. Production source insertion is rejected; a missing staging fixture only
exists in the rehearsal that rolls back. Native names, numbers, variants,
finishes, edition fields, prices and source policies remain unchanged.

The offline freezer reconstructs the same plan/table/decision from the frozen
descriptor, source manifest, actual inspected observations and matching saved
API bindings. Private local paths are removed while receipt hashes remain.
The downloader reuses accepted32 archive checks, suppresses imported bytecode
writes and uses only its own byte-frozen plan. Archive/expanded bytes are capped
at 64 MB and memory buffers one image. Duplicate members, unsafe paths, symlinks
and changed sizes/hashes fail before extraction. Every unique image is decoded
and every printing's four references validated without live database/storage or
artwork-provider requests.

## Protected production route

The route imports accepted48 metadata/source guards, accepted32 object/archive
helpers and the existing immutable publisher; it does not import mutable SS code.
`publish.mjs --execute` requires exact-main/manual-workflow/two-project guards
and `STACKR_ARTWORK_WIGGLYTUFF_CONFIRMATION=PUBLISH ARTWORK WIGGLYTUFF`.
Packages and public receipts use `STACKR_ARTWORK_WIGGLYTUFF_PACKAGES` and
`STACKR_ARTWORK_WIGGLYTUFF_OUTPUT`. Optional private output stays outside public
artifacts and must remain unset in hosted production. Full before-query results
remain private. The coordinator owns workflow, Git, live operations and ledger.

The guard preserves 28 printings, 28 normal variants, 56 names, one set and all
existing assets/links/sources; unexpected changes abort before commit. Reruns
create nothing. Rollback files hide only newly created exact-cohort assets and
retain immutable objects, links, old artwork and source policies. Production API
responses and served image bytes must be verified before items are closed.
