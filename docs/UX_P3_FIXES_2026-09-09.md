## Validation

The focused P3 suite verifies pinned capture identity, fresh-record metadata preservation and rejection of mismatched saved decisions. It runs in Platform CI. P1/P2, Scan Lab core, collection pricing and integration-repair checks protect the existing flows. App type checking, lint, production export and browser layout checks form the release validation; exact results and build identity are recorded in the release receipt.

The browser checks cover 320 × 640 and 393 × 852 layouts, active tab states, device-only bookmark disclosure, dialog dismissal and focus restoration, and the current Offers header/sign-in state. No comparable mover records were available in the preview, so populated mover wrapping is source-reviewed rather than presented as a live-data browser test.

The browser checks do not establish native VoiceOver, enlarged iPhone text, camera accuracy, successful authenticated offer actions, or the five-second navigation recognition test. Those remain device/user acceptance checks. This pass does not activate commerce, change catalogue data or create a new hosted environment.
