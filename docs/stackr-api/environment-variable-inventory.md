## Findings

- Public Expo variables include API URLs and public Supabase values. They must stay non-secret.
- Service-role keys, provider tokens, eBay credentials, Stripe secret, Shippo credentials and AI provider keys must remain backend/CI/function only.
- Current config mixes hard-coded public Supabase config with env-driven deployment config. Stage 2 should consolidate configuration behind the API client and deployment profiles.
