# Stackr beta readiness — 4 October 2026

The release targets a measured beta stopping point: a durable full-provider guide refresh, verified general-price backups, exact-language artwork boundaries, and the requested loading experience. It does not claim all-card pricing, complete foreign translations, or complete artwork. Scheduled runtime evidence and TestFlight delivery are recorded separately below and in the linked receipts.

## Pricing and daily refresh

TCGCSV imports every group in its English and Japanese catalogues, including unowned cards. Product and price feeds are retained even for groups that lack a safe Stackr mapping. Provider identity, language, collector number and finish checks remain mandatory; missing quotes and unresolved identities have explicit outcomes and retry dates. A completed feed scan is distinct from complete price coverage.

Both production and staging have the same forward migration bodies and aligned ledger versions. The bulk import initializes published outcomes in bounded pages, uses physical current-publication identities, and checkpoints each provider group. It avoids expanding the full catalogue for each card. A 191-candidate production query improved from 7,515 ms to 622 ms, with the same result count and no temporary spill. This measures that database query, not phone or whole-guide latency. See [performance evidence](daily-pricing-performance-20261004.json).

The production bulk reader accepts up to 100 known references in one request. Phone prices persist across launches, keep the last valid quote during refresh failures, and display source, update date and stale state. Price revisions are independent of catalogue revisions, allowing unchanged price rows to be omitted. Prices are scoped by account, server, language and estimate mode.

Cardmarket has 9,224 reviewed production mappings and 9,223 stored GBP estimates. All 74,620 retained products were processed over 150 pages, with 65,397 explicit repair records. Production identities were cross-checked against current physical publication membership rather than copying staging catalogue-version IDs. Cardmarket's public guide is a blended printing-level general estimate, with original EUR and dated ECB conversion evidence; it is never exact finish/condition/grade evidence or holdings valuation. A real production service-role backend read returned prices for 100/100 sampled printings, 99 from Cardmarket; exact mode returned zero Cardmarket estimates and the revision read omitted all 100 unchanged rows. That first/repeat sample took 10,614/3,184 ms including PostgREST and backend processing, so first-request latency is still a beta observation. See [import review](cardmarket-production-crosswalk-review-20261004.json) and [read receipt](cardmarket-production-read-20261004.json).

TCGCSV workers check at minute 13 UTC each hour; Cardmarket checks at minute 17. New daily provider revisions trigger a full refresh; unchanged feeds reuse retained files and checkpoints. Cardmarket has separate persistent 1 GB staging/production volumes. Its database-reviewed ledger loader, retained revision lookup and idempotent reviews preserve existing quotes across restarts and unchanged mapping reviews. Jobs have bounded deadlines, request pacing, leases and retries. Build success alone is not scheduled execution evidence; final run evidence belongs in [pricing readiness](pricing-readiness-20261004.json).

The existing eBay backup credentials passed OAuth and a bounded Browse request on 3 October at 22:58 UTC. The deployed adapter isolates credentials and coalesces token requests with deadlines. Browse supplies asking prices; this does not establish completed-sales coverage.

The latest measured production guide coverage is in [the current physical-publication coverage receipt](production-price-coverage-20261004.json). Cardmarket printing counts cannot simply be added to TCGCSV variant counts; the receipt removes overlap and retains unsupported languages in the full denominator. Coverage can grow while the first bulk sweep is running. Unmapped sets, absent provider quotes and unsupported finishes remain accepted beta gaps, with no false 100% claim.
