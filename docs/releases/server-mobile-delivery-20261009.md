- Completed approved English-name records now run on the backend: 19,315 printing names across Japanese, Traditional Chinese, Simplified Chinese and Korean. Card responses preserve native text and expose English supplement provenance; approved aliases remain explicitly non-authoritative. English search resolves the actual published printing before returning an alias match. Optional translation lookup has a 450 ms deadline and cannot discard stored search results. Generated translation maps stay out of the mobile archive.
- Saved quotes retain precedence in the bounded, authenticated `/v1/market/catalogue-prices` read. General mode can return a deterministic rarity/era provisional estimate only after verifying an unambiguous raw-card identity against the published version. Values are rounded to pennies and labelled `Estimated price (provisional baseline)`, low confidence, without sold evidence or timestamps, and unsuitable for exact-variant or holdings valuation. Optional metadata has a shared 450 ms cancellation/deadline; stalled reads retain existing quotes. This does not refresh providers or prove catalogue-wide coverage.
- Facts-only set-card reads select the published catalogue version. Stable weak ETags validate unchanged content independently of request IDs/timestamps. Personal pricing keeps its existing private/no-store/account boundaries.
