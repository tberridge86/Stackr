The sought use is restrained in-app set identification in collection, binder, search, checklist, card-detail and recognition-result screens. It excludes advertising, app-store branding, standalone downloads, exports, resale, corpus use, model training, and catalogue rewrites.

The applicable boundary in [`docs/stackrtcg-ip-operating-boundary.md`](../../stackrtcg-ip-operating-boundary.md) states: “The following uses require a source-specific and feature-specific written review before activation:” and includes “Display of provider-supplied set logos, expansion symbols, rarity graphics, pack artwork, or other marks beyond the minimum card-reference image needed for identification.” It further requires that an amber review identify “the asset or data, source, owner or licensor, permitted purpose, territory, term, transformation rights, storage rights, deletion requirements, attribution, downstream delivery rights, and approving person.”

The machine-readable identity, source, and hash evidence is in [traditional-chinese-six-set-mark-review-20260912.json](traditional-chinese-six-set-mark-review-20260912.json). Runtime lookup permits only exact canonical IDs combined with `zh-tw` or `zh-Hant`; it cannot fall back by set code, name, Japanese code collision, Simplified Chinese, or English.
