On 13 September 2026 the owner requested: “there arew still no binder arts for foreign language. we did all the images on here but none have been ingested.” This selects the six previously prepared marks for restrained in-app set identification in this release. The earlier review proposal remains unchanged as source provenance, rather than being rewritten to claim a licence.

The six files are SCA, SCB, SCC, SCD, S8a and SN, preserved from artifact `tc-published-logo-recovery-v4`, run `34701847752`, artifact `10299719637`. Their canonical Traditional Chinese set UUIDs, source pages and SHA-256 hashes are recorded in `traditional-chinese-six-set-mark-review-20260912.json` and the bundled manifest. All six files were visually inspected and their hashes are checked before release.

This is an owner-directed selection for the existing app's identification surfaces. It does not assert that the source supplied a new licence, expand the earlier TCGdex attestation, or authorize marketing, standalone downloads, training, resale or catalogue identity changes. The exact UUID and Traditional Chinese language must match. Japanese, Simplified Chinese and English cannot reuse these marks through code or name collisions.

No production database mutation or bulk catalogue ingestion is required: the original image bytes are bundled with the app. This adds six Traditional Chinese marks; it does not establish complete Chinese artwork coverage.
